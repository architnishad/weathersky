# 🌤️ WeatherSky

A simple and professional **Weather Application** built with Python and CustomTkinter.  
WeatherSky uses the **OpenWeatherMap API** to display current weather information and a 5-day forecast for selected cities.

## ✨ Features

- 🌡️ Current temperature
- 🌤️ Weather condition and description
- 💧 Humidity
- 💨 Wind speed
- 🌡️ Feels-like temperature
- 🔽 Atmospheric pressure
- 🌅 Sunrise time
- 🌇 Sunset time
- 📅 5-day weather forecast
- 🏙️ City selection using a dropdown
- 🔎 Search weather by pressing Enter or clicking the button
- ❌ Error messages for invalid cities and connection problems
- 🎨 Clean and user-friendly GUI
- 🖥️ Can be converted into a Windows `.exe`

## 🛠️ Technologies Used

- **Python**
- **CustomTkinter**
- **Requests**
- **Pillow (PIL)**
- **OpenWeatherMap API**
